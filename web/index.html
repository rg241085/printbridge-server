    ⚙️ Print settings

    Ye settings PDF, photo, aur (laptop par MS Office ho to) Word/Excel/PowerPoint par chalti hain.

    📷 Scan karke PDF banaiye

    Document ki photo lijiye, kone theek kijiye, aur PDF banakar print ya share kijiye.

    📶 Internet band hai? Laptop window mein "Bina internet" wala QR scan kijiye (phone aur laptop ek WiFi par hon).

    📲 App install kijiye

    Install karne ke baad WhatsApp, Gallery ya File Manager mein kisi bhi document par Share → PrintBridge dabaiye. Seedha yahan aa jaayega.

    Haal ki prints

      Abhi tak kuch print nahi hua.

      💡 WhatsApp se seedha print: document par lamba dabaiye → Share (↗) → PrintBridge. Iske liye app install honi chahiye (Chrome menu ⋮ → "Install app" / "Add to Home screen").

      🧑 Passport size photo

      Saamne se li gayi photo chuniye (halki deewar ke aage). Photo ko khiskakar aur bada-chhota karke chehra dabbe ke beech mein laaiye.

      🪪 ID card print

      Aadhaar, PAN, License, Voter ID… dono taraf ki photo lijiye. Card A4 kaagaz par asli size (85.6 × 54 mm) mein, katne ki line ke saath chhapega.

      Peeche ka hissa (zaroori nahi)

      Photo ke baad card ke chaaron kone theek kijiye. Card par tap karke dobara theek kar sakte hain.

      Page par tap = kone / rang theek karein ya dobara photo lein. Page ko dabakar rakhiye aur khiskaiye = kram badlein.
