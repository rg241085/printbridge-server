# PrintBridge

Mobile se seedha laptop ke printer par print. WhatsApp/Gallery se **Share → PrintBridge**.

- **Website / phone app:** https://printbridge.onrender.com
- **Laptop program (Windows):** https://printbridge.onrender.com/download

## Folder
| Folder / file | Kya hai |
|---|---|
| `app.py`, `web/` | Server + phone app + download page (Render par chalta hai) |
| `laptop/` | Laptop wala program. GitHub ise apne aap `PrintBridge.exe` bana deta hai |
| `.github/workflows/build-windows.yml` | exe banane ka setup (Actions) |
| `render.yaml` | Render ki settings |
